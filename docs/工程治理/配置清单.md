# 配置清单

## 1. 配置加载机制

配置统一由 `backend/src/core/config.py` 的 `Settings` 管理，取值优先级从高到低：

1. **真实环境变量**（容器 / CI 注入，`os.environ`）
2. **`.env` 文件**（`ENV_FILE_PATH` 指向 `backend/src/.env`，本地开发；Docker 部署挂载 `.env.server` 到该路径）
3. **插件默认值**（`PluginSettingsSource` 从各插件 `plugin.toml` 的 `[settings]` 加载，仅兜底 config.py 中无默认值的字段）

> 缺 `.env` 时后端会提示创建并退出（不再静默复制模板）；容器 / CI 已注入关键环境变量时正常继续。

## 2. 模块依赖配置清单

三个 env 文件已实测均可完整实例化 `Settings`（必填字段全覆盖，部分由插件兜底）。

| 模块 | 关键字段 | 本地 `.env` | 部署 `.env.server` | 说明 |
| --- | --- | --- | --- | --- |
| 当前环境 | `ENVIRONMENT` | `dev` | `prod` | 仅允许 `dev` / `prod`；`prod` 时自动关闭 OpenAPI、启用监控与 RabbitMQ broker |
| 数据库 | `DATABASE_TYPE/HOST/PORT/USER/PASSWORD/SOURCES` | ✓ | ✓ | URL 由字段组装；`DATABASE_SCHEMA` 默认 `ragf`；测试自动用 `ragf_test` |
| JWT / Token | `TOKEN_SECRET_KEY` | ✓（开发值） | ✓（独立值） | **部署必须更换**为 `secrets.token_urlsafe(32)`；过期时间等有默认 |
| Redis | `REDIS_HOST/PORT/PASSWORD/DATABASE` | ✓ | ✓ | 缓存、限流、Celery broker（db 1）、Snowflake 心跳共用 |
| 消息队列 | `CELERY_BROKER_REDIS_DATABASE`、`CELERY_RABBITMQ_*` | ✓ | ✓ | broker 默认 `redis`；`prod` 自动切 `rabbitmq`；结果后端为数据库 |
| 定时任务 | （复用队列/数据库） | — | — | beat 调度器为 `DatabaseScheduler`，表由启动自动创建 |
| Snowflake ID | `SNOWFLAKE_ENABLED` 等 | 默认关 | 默认关 | 需分布式 ID 时开启并配置 worker/datacenter |
| OAuth2 | `OAUTH2_GITHUB/GOOGLE_*`、回调 URI | ✓ | ✓（已补齐占位） | **部署将 `your-domain` 替换为实际域名**，否则回调指向 localhost |
| Email | `EMAIL_HOST/PORT/SSL/USERNAME/PASSWORD` | ✓ | ✓（已补齐占位） | SMTP 服务商配置；密码用授权码 |
| 插件 | `CODE_GENERATOR_DOWNLOAD_ZIP_FILENAME`、`PLUGIN_*` | ✓ | ✓ | 插件配置也可在各自 `plugin.toml` 提供默认 |
| 监控 | `GRAFANA_*` | 默认关 | ✓ | `prod` 自动 `GRAFANA_METRICS_ENABLE=True`；OTLP 指向 `ragf_alloy:4317` |
| 缓存 | `CACHE_*` | 默认 | 默认 | 本地缓存 + Redis 缓存，无需显式配置 |

## 3. 实测结论

- `backend/src/.env`、`backend/src/.env.example`、`deploy/backend/docker-compose/.env.server` 均可完整实例化 `Settings` ✓
- 全部 35 个必填字段均有取值（环境变量 / `.env` / 插件兜底三选一）
- 已修复缺口：`.env.server` 此前缺少 `OAUTH2_*` 回调 URI 与 `EMAIL_*` SMTP 配置，会静默使用插件默认（localhost）——已显式补齐并注释提醒

## 4. 部署注意事项

- **Token 密钥**：`TOKEN_SECRET_KEY` 必须与开发环境不同且足够随机
- **OAuth2 回调**：`OAUTH2_*_REDIRECT_URI` 与前端地址必须为公网可达地址
- **Email**：SMTP 主机/端口/SSL 按服务商填写，密码建议使用授权码
- **数据库账号**：与根 `.env` 的 `POSTGRES_*` 保持一致（见 [环境变量](环境变量.md)，可用 `task env:check` 校验）
- 修改配置后重启验证：`task dev`（本地）/ `docker compose restart ragf_server`（部署）
