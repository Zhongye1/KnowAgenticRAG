# 首页新增「数据源与工具集成」段

状态：implemented
类型：feature
Owner：web/src/pages/home/ui/integration-section.tsx

## 问题

首页讲完了能力与任务链，但没有回答「资料从哪里进来、在哪里被使用、模型能不能换」。参考一张外部产品的首页截图，需要补一段「导入侧 / 品牌位 / 客户端渠道侧 + 模型厂商条」。

## 决策

1. 新增 `web/src/pages/home/ui/integration-section.tsx`，挂在任务链段之后、`SiteFooter` 之前 —— 参考图末尾的模型厂商条读起来就是收尾块。
2. 结构与文案照参考图（中文原文）：大标题靠左、说明靠右同一行；一条通栏横线；下方三列，列间竖分隔线：
   - 左列「导入与同步资料」：金色图标 + 说明 + 十个数据源标签 + 「数据源集成 →」。
   - 中列：参考图放的是外部产品的字标，这里换成自己的品牌位（头像 + `KnowAgenticRAG` + 团队知识库与智能体 + 金色「理解 · 检索 · 推理 · 行动」）。
   - 右列「在常用工具中访问」：金色图标 + 说明 + 十一个渠道标签 + 「客户端与渠道 →」，再由一条内部分隔线接「通过 MCP Server 共享知识」+「配置 MCP 端点 →」。
   - 末尾一行「模型由你选择 · 内置 30 家厂商」+「查看全部 →」，下面是十二家厂商名单。
3. 配色取样自参考图（段底 `#f5f2ed`、标签底白 + `#e6e1d7` 边框、分隔线 `#e6e1d7`），金色图标复用 `--accent-gold`，文字走页面 token。全部写在 `src/styles/home.css` 的 `.integration-*`（`.tsx` 里不允许 hex）。
4. 视口 ≤1024px 转单列，竖线改为分段的上边框。该媒体查询必须排在基础规则之后（同权重下源顺序决定胜负，写在前面会被基础规则反超）。
5. 本节内部间距写在 CSS：`h3`/`p` 的上下边距受无层 `:where` 重置影响只能同层写，其余间距属于同一段节奏，放在一起读更顺。

## 替代方案

- 品牌位照抄参考图的字标：那是别家产品的标识，不能出现在本仓页面上，因此换成自己的品牌位。
- 标签带品牌图标：参考图的标签是「logo + 名称」，这里没有可用的图标资源，先做纯文字标签；要补图标得先有素材与授权。
- 模型厂商用 logo 展示：同上，先出文字名单。
- 中列直接删掉改成两列：参考图的三列节奏（导入 → 品牌 → 使用）本身就是这段的叙事，删掉会变成两段列表。

## 后果

- 首页多一段三列内容区与一组新页面级色值（`#f5f2ed` / `#e6e1d7`），限定在 `.integration` 作用域内。
- 标签、厂商名单是纯文字，与参考图的「图标 + 文字」有可见差距，等素材齐了再补。
- 四个「→」链接指向 `outbound` 里最接近的文档地址（`docsKnowledge` / `docsApi` / `docsMcp` / `docs`），文档站有更贴切的入口时改常量即可。
