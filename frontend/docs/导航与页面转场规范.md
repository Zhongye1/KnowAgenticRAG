# 导航与页面转场规范

> 本节内容准备追加到仓库根 `docs/frontend/前端架构设计.md`（因沙箱权限暂存于此）。

## 原则

- 用户可见的跳转入口一律使用 `<Link viewTransition>` / `<NavLink viewTransition>`（声明式），
  把页面转场、可访问性、新标签打开等能力白拿到手。
- 只有「代码时机」决定的跳转（表单提交成功、鉴权重定向、定时器等）才使用 `navigate()`（编程式）。
- 编程式跳转（`navigate()` / `<Navigate>`）**不会**触发 View Transition，这是预期行为；
  需要转场时优先把入口改造成 Link，而不是依赖编程式跳转。

## Link 跳转 vs 编程式跳转

| 维度 | `<Link viewTransition>`（声明式） | `navigate()`（编程式） |
| --- | --- | --- |
| 触发方式 | 渲染时声明，点击由 Router 接管 | 事件回调 / 异步完成后调用 |
| DOM | 真实 `<a href>` | 无 DOM |
| 页面转场 | ✅ 由 `viewTransition` prop 触发 | ❌ `NavigateOptions` 无此选项 |
| 新标签打开 / 中键 | ✅ 浏览器原生行为 | ❌ |
| 语义 / 可访问性 | ✅ 可聚焦、可爬取 | ⚠️ 依赖调用方保证 |
| 典型场景 | 导航菜单、CTA、面包屑、分页、列表项 | 表单提交后跳转、登出重定向、权限守卫 |

## 页面转场（View Transitions API）

- 触发：react-router 的 `Link` / `NavLink` 的 `viewTransition` prop；
  Router 内部先检测 `document.startViewTransition`，不支持的浏览器自动降级为普通跳转。
- 范围：只有页面内容（`PageTransition` 容器，`view-transition-name: page-content`）播放
  滑入 / 滑出动画；NavBar、侧边栏等常驻元素留在 root 快照中保持静止。
- 主题切换兼容：DayNightSwitcher 切换期间给 `<html>` 加 `theme-transitioning` 类，
  页面内容临时并入 root 快照，圆形扩散动画覆盖整页；切换结束移除该类。
- 动效：旧页向左淡出（`vt-page-out` 0.25s）、新页从右滑入（`vt-page-in` 0.3s）；
  `prefers-reduced-motion: reduce` 时关闭动画。
